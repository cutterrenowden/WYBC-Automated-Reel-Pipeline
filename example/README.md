# Example: Tyler Gilbert no-hitter

Source: a 7 minute broadcast call ([YouTube](https://www.youtube.com/watch?v=WFlYE8F-_xo)). The
mp4 went through ReelPipe with 5 clips requested. This folder is the output, the same layout the
app writes to `out/video/gilbert-nohitter/`:

```
clips.json    the chosen cuts
clips/        the five clips with matching .srt subtitle files
handoff/      resolve timeline (reels.xml, reels.edl), clips.csv, REPORT.md
```

Watch one: [clips/05_gilbert-throws-a-no-hitter.mp4](clips/05_gilbert-throws-a-no-hitter.mp4).
